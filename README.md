# Data Science with Python 🐍

A comprehensive learning journey to master **Data Science using Python**. This repository covers everything from Python fundamentals to advanced data analysis and visualization techniques.

---

## 📚 Course Contents

### **Module 1: Python Fundamentals**
- Python Basics (Variables, Data Types, Operators)
- Strings and String Methods
- Control Structures (`if-else`, `elif`)
- Looping Constructs (`for`, `while`)
- List, Tuple, Dictionary, and Set
- List Comprehensions

### **Module 2: Functions & Modular Code**
- User-defined Functions
- Arguments (`*args`, `**kwargs`)
- Lambda Functions
- Map, Filter, and Reduce
- Scope and Recursion

### **Module 3: NumPy - Numerical Computing**
- NumPy Arrays
- Array Operations and Broadcasting
- Indexing and Slicing
- Mathematical & Statistical Functions
- Random Number Generation

### **Module 4: Pandas - Data Manipulation**
- Series and DataFrame
- Data Importing & Exporting (CSV, Excel, JSON, etc.)
- Data Cleaning and Preprocessing
- Handling Missing Values
- Filtering, Sorting, and Grouping
- **Merging, Joining, Concatenation** (`pd.merge`, `pd.concat`, `join`)
- Pivot Tables and Crosstab

### **Module 5: Data Visualization**
- Matplotlib (Basic & Advanced Plots)
- Seaborn (Statistical Visualizations)
- Histograms, Box plots, Scatter plots, Heatmaps
- Pairplot, Countplot, Violin plots
- Customizing plots (Style, Color, Labels, Legends)

### **Module 6: Time Series Analysis**
- Working with DateTime Data
- Resampling and Shifting
- Rolling Windows & Moving Averages
- Time Series Visualization
- Trend, Seasonality, and Decomposition

### **Module 7: Advanced Topics**
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Handling Categorical Data
- Memory Optimization
- Real-world Projects & Case Studies
